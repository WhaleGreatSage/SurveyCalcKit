# Code of Conduct

## Our Pledge

We want SurveyCalcKit to be a welcoming project for students, beginners, educators, and professional contributors.

## Expected Behavior

- Be respectful and constructive.
- Explain technical feedback clearly.
- Assume good intent when discussing mistakes.
- Help keep examples and documentation beginner-friendly.

## Unacceptable Behavior

- Harassment or personal attacks.
- Insults based on identity, background, or experience level.
- Publishing private information without permission.
- Repeated disruptive behavior in issues or pull requests.

## Enforcement

Maintainers may edit, hide, or remove comments and may limit participation for behavior that harms the project community.
