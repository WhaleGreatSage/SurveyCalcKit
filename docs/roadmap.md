# Roadmap

SurveyCalcKit is intended to grow slowly and remain beginner-friendly.

## Version 0.1

- Core point parsing.
- Traverse segment calculations.
- Elevation and slope calculations.
- Coordinate translation, scale, and rotation.
- CLI reports.
- Basic WinForms UI.
- xUnit tests and GitHub Actions.

## Version 0.2

- Closed traverse closure calculation and Bowditch adjustment.
- More report formatting options.
- Optional Chinese UI labels.
- CSV export for segment tables.
- More sample datasets and classroom exercises.

## Version 0.3

- Beginner-friendly adjustment examples.
- NuGet package metadata for `SurveyCalcKit.Core`.

## Later Ideas

- Spreadsheet import/export helpers.
- More coordinate transformation modes.
- Additional surveying formulas with worked examples.
- Better localization infrastructure.
