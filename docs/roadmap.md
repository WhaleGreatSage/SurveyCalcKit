# Roadmap

SurveyCalcKit is intended to grow slowly and remain beginner-friendly.

## Version 0.1

- Core point parsing.
- Traverse segment calculations.
- Elevation and slope calculations.
- Coordinate translation, scale, and rotation.
- CLI reports.
- Basic WinForms UI.
- xUnit tests and GitHub Actions.

## Version 0.2

- Closed traverse closure calculation and Bowditch adjustment.
- Leveling route closure check and simple height adjustment.
- Excel import/export for point data and calculation results.
- Coordinate forward calculation from start point, azimuth, and distance.
- Coordinate inverse calculation between two known points.
- Batch segment table generation with cumulative distance.
- Angle format conversion between decimal degrees, DMS, and radians.
- Markdown report export for coursework and GitHub documentation.
- Chainage and offset calculation for target points against a straight baseline.
- Enhanced closed traverse quality evaluation with relative and angular closure checks.
- Circular curve element calculation for road alignment workflows.
- Vertical curve calculation for road profile design elevations.
- Batch stakeout point coordinate calculation from chainage and offset records.
- Simple DXF export for point records, labels, and connected polylines.
- More report formatting options.
- Optional Chinese UI labels.
- CSV export for segment tables.
- More sample datasets and classroom exercises.

## Version 0.3

- Beginner-friendly adjustment examples.
- NuGet package metadata for `SurveyCalcKit.Core`.

## Later Ideas

- Road curve element calculation.
- Stakeout report export.
- Least squares traverse adjustment.

- Combined horizontal and vertical alignment.
