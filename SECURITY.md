# Security Policy

SurveyCalcKit is a local calculation toolkit and does not currently provide a network service.

## Reporting a Vulnerability

Please report security concerns through GitHub issues if the repository does not yet have private security advisories enabled.

Include:

- A short description of the issue.
- Steps to reproduce.
- Potential impact.
- Suggested mitigation, if known.

Do not include sensitive private data in public reports.
